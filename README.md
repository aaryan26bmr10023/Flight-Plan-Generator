# Flight Plan Generator

## 1. Project Title

Flight Plan Generator

## 2. Overview

A simple Python terminal program that creates an educational digital
flight plan.

## 3. Features

-   Select departure airport
-   Select destination airport
-   Select aircraft
-   Enter passenger count
-   Calculate distance
-   Calculate flight time
-   Calculate fuel
-   Show weather information
-   Generate waypoints
-   Show departure and arrival time
-   Display the final flight plan

## 4. Technologies Used

-   Python 3
-   Visual Studio Code
-   Git and GitHub
-   Python built-in modules

No external packages are required.

## 5. How to Install and Run

### Step 1

Install Python 3.

### Step 2

Download or clone this repository.

### Step 3

Open the project folder in VS Code or a terminal.

### Step 4

Run:

``` text
python main.py
```

On Windows, you can also use:

``` text
py main.py
```

## 6. Testing

Run the program and test: - Valid airport numbers - Invalid airport
numbers - Valid aircraft numbers - Invalid aircraft numbers - Valid
passenger numbers - Invalid passenger input

The program shows an error message for invalid input.
