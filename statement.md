# Project Statement

## Project Title

Flight Plan Generator

## Problem Statement

Flight planning contains many details such as airports, aircraft,
passengers, distance, time, fuel and route information. Managing these
details can be difficult for a beginner.

This project provides a simple Python program that takes basic flight
information and creates an organized digital flight plan.

## Scope of the Project

The project covers: - Airport selection - Aircraft selection - Passenger
input - Distance calculation - Flight time calculation - Fuel
estimation - Weather display - Waypoint generation - Flight plan display

The project is an educational simulation and does not use live aviation
data.

## Target Users

-   Python students
-   Beginners learning programming
-   Teachers evaluating Python fundamentals

## High-Level Features

1.  Airport and passenger input
2.  Aircraft selection
3.  Flight calculations
4.  Route and waypoint generation
5.  Weather information
6.  Final flight plan generation
